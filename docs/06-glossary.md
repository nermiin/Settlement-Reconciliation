# Glossary — Settlement & Reconciliation

| Term | Definition |
|------|------------|
| **Clearing** | Exchange of transaction data between acquirer and issuer via scheme |
| **Settlement** | Actual funds movement following clearing |
| **Nostro** | Our account held at another bank (scheme settlement account) |
| **VSS** | Visa Settlement Service — settlement reporting |
| **IPM** | Mastercard Integrated Product Messages — clearing/settlement format |
| **Break** | Unmatched or mismatched record requiring investigation |
| **T+1** | Settlement one business day after transaction date |
| **Suspense Account** | Temporary GL holding until reconciliation completes |
| **Materiality** | Threshold above which breaks require formal escalation |
